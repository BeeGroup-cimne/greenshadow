== New regional pipelines (greenshadow.pipelines; see docs/pipelines.md "Adding a region") ==
Goal: the same products as the Catalan case (DSM/DEM, roofs + rooftop PV, crop rows, parcel PV and
agrivoltaics) in each region, so the results can be compared. For each one, gather the equivalents of what
Catalonia uses: administrative limits (hypercadaster/INE), cadastral building footprints (Spanish cadastre)
and agricultural parcels with their declared use (SIGPAC).

- Generalise the Catalan-specific parts before adding regions:
  - Parcel adapter: plan_parcel_pv_scenarios, detect_crop_rows and filter_agricultural_parcels key on
    uso_sigpac and the SIGPAC 7-tuple id. Map each region's LPIS crop codes to the SIGPAC use groups (or to
    the HCAT taxonomy that fiboa/EuroCrops already provide) so SIGPAC_USE_MARGIN_EUR_HA,
    SIGPAC_SPACING_PRIORS and SIGPAC_USE_SHADE_RESPONSE keep working; per-region margins table.
  - LiDAR class profile per provider (classification sets of the three digital models, building /
    vegetation / bridge codes, crane removal and SVF class lists) instead of the ICGC codes hard-wired in
    pipelines/catalonia.py.
  - Per-region epsg and tz_local; acquisition date from each provider's metadata (vegetation growth).
  - Building footprints from a generic source when there is no open cadastre: Overture Maps buildings
    (pip install overturemaps) or EUBUCCO (https://eubucco.com/data/), for the classification correction.
  - Administrative limits fallback for all three: Eurostat GISCO LAU (EU-wide municipalities, one source).
